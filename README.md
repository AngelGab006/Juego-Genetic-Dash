# Objetivos del proyecto
Replicar el juego Geometri Dash, estas partes en especifico:

1 - El juego será de running constante tipo Geometry Dash.

2 - Debe haber un obstáculo tipo "púa" que "mate" al jugador cuando colisione con el mismo.

3 - Debe morir el jugador cuando colisione de frente o encima con un bloque sólido.

4 - Debe añadir un trampolín que impulse al jugador verticalmente una distancia más alta que el salto normal. (ver nivel 2 de GD)

5 - Debe añadir una orbe de doble salto. (ver nivel 3 de GD)

6 - Debe añadir modo "nave". Este modo debe activarse al entrar a un portal de nave y desactivarse al entrar a portal de normalidad. (ver nivel 1 de GD)

7 - Crearán 3 niveles en donde se pueda ver el funcionamiento de todo lo requerido.

8 - El juego debe verse gráficamente y sonoramente adecuado.
